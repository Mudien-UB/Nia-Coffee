# Nia Caffee – Landing Page Website Café

A personal project landing page for a café website, built using modern React JS stack. Features product menu with pagination, sort, and search functionalities using dummy data and free public APIs.

---

## Tech Stack

- **Frontend Framework:** React JS (Vite)  
- **Styling:** Tailwind CSS  
- **Routing:** React Router DOM  
- **State Management:** React Redux  
- **Icons:** React Icons  

---

## Features

- Beautiful landing page for a fictional café  
- Product menu section with:
  - Pagination  
  - Sort by price/name  
  - Search product by keyword  
- Uses dummy data & free public API (e.g., [FakeStoreAPI](https://fakestoreapi.com))  
- Fully responsive and mobile-friendly layout  
- Component-based architecture  

---

## Requirements

- Node.js >= 18  
- NPM or Yarn  
- Vite  
- Browser (Chrome, Firefox, etc.)

---

## Installation

```bash
# Clone the repository
git clone https://github.com/yourusername/nia-caffee.git
cd nia-caffee

# Install dependencies
npm install

# Start the development server
npm run dev

```
